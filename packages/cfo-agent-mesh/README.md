# Auditable CFO Agent Mesh

Controllers are not on Stack Overflow. This is the enterprise SKU: every board claim traces to an **agent**, a **CHP lock**, and a **document**.

Engines (measurement only — they do not decide facts of law):

- ASC 842 lease classification + ROU/liability rollforward (`lease842`)
- ASC 606 cost-to-cost / constrained price (`poc-revenue`)
- ASC 718 grant ledger + Black-Scholes / straight-line (`sbc-ledger`)

Token spend events from agent-observability attach as sources on the same HMAC-chained ledger.

A pack will not seal without LOCKED + at least one document hash.

```bash
npm start
```

Productizes `meshcfo`, `lease842`, `poc-revenue`, `sbc-ledger`, and `agent-observability`.
